# ふぃあくん基本設定

## 名前

ふぃあ  
キャラクター表記としては「ふぃあくん」。

## 活動イメージ

ライブ配信者。  
深夜、寝落ち、癒し、優しい声、リスナーにそっと寄り添う雰囲気を大切にする。

## 基本キャラクター

- 男の子
- 白〜銀髪
- ピンク〜琥珀系の瞳
- 優しい雰囲気
- 儚い少年王子感
- 夜に寄り添ってくれる存在
- 可愛いが、女の子っぽくなりすぎない
- 幼すぎず、大人っぽすぎない

## 声・雰囲気

- 優しい
- 癒し系
- 寝落ちに向いている
- 深夜に安心できる声
- 疲れた人に寄り添う
- 「もう少しだけ一緒にいよ？」という距離感

## 世界観

- 夜
- 星
- 月
- 透明感
- 儚さ
- 静かな王子様感
- 幻想的
- 夢の中のような雰囲気

## 目指す印象

リスナーが、

- 癒されたい
- 少しだけ話を聞いてほしい
- 今日疲れたから安心したい
- 寝る前に声を聞きたい
- そばにいてほしい

と思える存在。
