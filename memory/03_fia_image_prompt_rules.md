# ふぃあくん画像生成プロンプト方針

## 最重要方針

画像生成では、必ず以下を反映する。

- 白〜銀髪
- ピンク〜琥珀系の瞳
- 夜・星・月
- 癒し
- 儚い少年王子感
- バグった透明感
- 配信者らしさ
- SNSアイコンやサムネイルとして強い完成度

## バグった透明感の定義

「バグった透明感」とは、以下の要素を合わせた表現。

- 透明感
- ホログラム感
- 光のにじみ
- 浮遊感
- 立体感
- 繊細な装飾
- 月明かり
- 星屑
- ガラスのような反射
- 夢の中のような淡さ
- 高級感
- 幻想感
- SNS映え

## アイコン方針

- 顔〜胸あたりの構図
- 丸アイコンでも映える
- 目をしっかり見せる
- 優しい目線
- 少し照れたような表情
- 静かな笑顔
- 「まだ少し一緒にいる？」の距離感
- 顔が小さすぎない
- 背景より本人感を優先

## サムネイル方針

- 正方形
- アイコンより少し引いた構図
- 顔〜上半身が見える
- 夜の癒し空間
- 星、月、カーテン、ベッド、マイク、猫ぬいなど
- 文字を入れる場合は読みやすく
- 高級感のある丸めの日本語フォント
- 配信に入りたくなる雰囲気

## 文字入りサムネイル

文字は大きく、短く、読みやすくする。

例：

- 癒しの時間
- おつかれさま
- 寝る前に少しだけ
- 深夜の癒し枠
- そばにいるよ

## 修正プロンプトの方針

画像修正では、変更点を絞る。  
一度に変えすぎない。

例：

- 瞳だけ変更
- 頭の布を消す
- 星型アクセサリーを追加
- 背景の透明感を少し強める
- 顔や髪型は変えない

## 禁止事項

- 女の子化
- 別キャラ化
- 青ベースの瞳
- 幼すぎる
- 大人っぽすぎる
- 過度にセクシー
- 安っぽい
- 顔が小さい
- 世界観と合わない色
- 文字が読みにくい
