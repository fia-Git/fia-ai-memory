# fia-ai-memory

ふぃあくんのキャラクター設定、好み、画像生成ルールを管理するリポジトリ。

AIに読み込ませる時は、以下の順番で読む。

1. `character/fia-kun.md`
2. `character/fia-kun-preferences.md`
3. `prompts/image-generation/image-generation-rules.md`

## 目的

- ふぃあくんのキャラクター性を安定させる
- AI生成で別キャラクター化しないようにする
- AIが出しがちな平均的・典型的な表現を避ける
- 公式ページ、SNS投稿、比較企画などで一貫した品質を保つ

## 重要方針

ふぃあくんは、AIテンプレート美形ではなく、唯一無二の個性を持つキャラクター。

月、星、羽、結晶などのモチーフ自体は禁止しない。  
ただし、AIが自動で出しがちな雑な使い方や平均的な配置は避ける。

すべての要素は、プロが意図して配置したように見せる。
